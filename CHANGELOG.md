# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

rcln is **pre-1.0**: the public API, the database schema and the permission
model may all change without a major-version bump. Development moves in phases —
[`.kb/STATUS.md`](.kb/STATUS.md) is the living ledger of what is built and what
is next; this file records released versions.
